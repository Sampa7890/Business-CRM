Installation & Setup:-
1.Copy the business_crm project folder to the htdocs directory of XAMPP.
2.Start Apache and MySQL from the XAMPP control panel.
3.Open phpMyAdmin in your browser.
4.Create a new database named business_crm.
5.Import the provided business_crm.sql file into the database.
6.If you are using a different database name, update the database credentials in db.php.
7.Open a web browser and navigate to:  http://localhost/business_crm.
8.Log in using the appropriate Admin or Employee credentials.

9.Admin Login Information:-
        Username: admin@businesscrm.com 
        Password: admin123

10.EMPLOYEE Login Information:-
        Employee accounts are created by the Admin through the Employee Management
        module.

        When a new employee is added, the system automatically generates a unique 
        Employee Username and Password.

        The generated credentials should be saved by the Admin and provided to the employee.

        Employees can log in using their assigned Username and Password.
